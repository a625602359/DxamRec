DxamRec —— 后台录像测试 App
================================

【这个 App 能干什么】
用摄像头在后台录像（熄屏也行），并支持用一条 adb 命令遥控开关。
仅限在你自己设备上做测试/自用。

【重要限制，先看】
1. 录像时状态栏一定会亮摄像头指示，通知栏一定有一条常驻通知，
   这是安卓系统强制的，任何 App 都一样，关不掉。
2. 一加/OPPO 的 ColorOS 会杀后台，装好后必须去
   设置 -> 应用 -> 应用管理 -> DxamRec -> 耗电管理 -> 允许后台活动 / 不受限制，
   再打开“允许自启动”，否则熄屏一会就被回收。
3. 录像文件保存在：内部存储/Movies/DxamRec/ 下。

【怎么编译安装】
方法一（电脑，推荐）：
  1. 把整个 DxamRec 文件夹拷到电脑
  2. 用 Android Studio 打开该文件夹，等它自动同步（首次会下载依赖，需要联网）
  3. 连上手机，点 Run 绿色三角，装到手机上

方法二（命令行）：
  在项目根目录执行  ./gradlew installDebug

【第一次使用】
1. 打开 App，点“授权”，弹窗里把 相机 和 通知 都点允许。
   （不授权的话，后台录像起不来）
2. 点“立即开始录像”，这时状态栏会出现摄像头小点、通知栏出现常驻通知，
   说明已经在录了。
3. 点“停止录像”结束，去 相册/文件管理 -> Movies/DxamRec 看视频。

【用脚本遥控（可选，进阶）】
App 装好且授权之后，用电脑 adb 或本机 shell 执行：
  开始:  am broadcast -a com.dxam.rec.START_REC
  停止:  am broadcast -a com.dxam.rec.STOP_REC

如果没反应，多半是两种原因：
  a) 还没在 App 里授权过相机/通知
  b) ColorOS 把自启动关了 / 电池没设成不受限

【常见问题】
Q: 为什么状态栏那个点是绿的/亮的？
A: 那是系统在告诉用户“摄像头正在使用”，属于隐私保护，不能隐藏，正常现象。

Q: 装好后点开始没反应？
A: 先确认相机权限给了、通知权限给了；再看 ColorOS 电池白名单。

Q: 能同时用系统相机吗？
A: 一般不能，摄像头同一时刻通常只被一个 App 占用。
